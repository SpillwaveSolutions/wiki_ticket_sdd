# Warn at plan capture when a task title references a ticket number

`01KYNHEVZSBJ43P0CE2EBXT7Y0` · task/feature · **done**

Plans whose task titles quote a ticket number in prose are a reliable source of phantom duplicate items — someone sees the apparent duplicate and links it to the ticket it names, which is the mistake that corrupts the ticket.

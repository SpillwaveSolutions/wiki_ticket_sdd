## Change Log

- [[Ticket-01KZ721Y7CM5Q0NTQC31QB2HGS]] Add native Codex plugin compatibility — Package the existing worklog skills for native Codex discovery, document installation and host behavior, and preserve the Claude Code and Grok Build experience.
- [[Ticket-01KZ9JTC1SPC6PHXHE6RAGDW9G]] Codex PR: regenerate the index so CI goes green — The Codex packaging change edited the work log and the roadmap without rebuilding the generated index, so the committed inventory and publish manifest no longer describe the log.
- [[Ticket-01KZ9JTC6VAC8105JAGT0WRYVH]] Ship the worklog hooks to Codex, not just the skills — The Codex package currently carries skills and no lifecycle hooks, on the stated grounds that the two hosts use incompatible hook schemas and that Codex lacks a plan-approval event.
- [[Ticket-01KZ9JTCBS4W06FVSHZPZMQHCE]] Open the 0.22.0 changelog section and bump the version lockstep — The first feature of a new release wave is supposed to open that release's unreleased changelog section and raise the version everywhere it is recorded, in the same commit.
- [[Ticket-01KZ9JTCGG2QJYXW973RJCWDR2]] Restore the file patterns in two skill descriptions — The plan-capture and status-report descriptions lost the concrete filename patterns they used to spell out.
- [[Ticket-01KZ9KGE49EAS3VEFDNFTVM1PV]] merge-rescue can invert an item's state — When a compaction lands mid-branch, the rescue re-emits the branch's own events with fresh identifiers so the snapshot cannot overwrite them.
- [[Ticket-01KZ9MD733ZEBNT3B2X1672FB0]] A stray main block hides seven dispatcher tests — The dispatcher test file has its run-as-a-script block in the middle rather than at the end.

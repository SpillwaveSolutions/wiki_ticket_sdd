## Change Log

- [[Ticket-01KZCC0F3QYFX9QAKTYVZ01TFK]] doc-verify accepts a citation whose range is merely close — The verifier asks only whether the cited symbol appears somewhere inside the cited line range.
- [[Ticket-01KZCCG7010S0Q0Y6PF6NN27C2]] Compaction hides shipped work from the status report — A weekly report counts an item as shipped only when a close event falls inside the window.
- [[Ticket-01KZCYXC49J4M5NECS620EFXNB]] Composite item ids write junk events on the non-resolving sync commands — worklog's item is a single positional, so close with two ids quoted together puts both in one string.
- [[Ticket-01KZCZQ2561TW1BPT3Z9AM75SZ]] The citation warning fires on every commit and can never clear — The pre-commit hook reports every citation problem in the repository, and all forty-eight live in frozen documents that policy says stay frozen.
- [[Ticket-01KZD8FBVV2AP9JKMMCX1YWDEP]] Cut v0.23.0 release — Release four correctness fixes: the citation verifier now judges where a citation starts, the status report survives compaction, the commit-time citation warning is scoped to what the commit touches, and composite item ids are rejected before they write junk events.

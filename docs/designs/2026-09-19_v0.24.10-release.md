### Landed in the architecture

- **Retention** (`bin/compact.py`, v0.24.10; corrected after the tag).
  Compaction evicts closed snapshots older than epic 730 / story 180 / task 90 /
  subtask 90 days, then a FIFO cap of 1000, into a third log file,
  `.work/archive.jsonl`. Nothing is deleted. Verify folds all three files. The
  tagged compactor re-snapshotted archived items every active night because the
  "already snapshotted" check folded `done.jsonl` alone; the post-tag fix folds
  the archive too, prunes the archive by item, counts only `done.jsonl` against
  the cap, gives an unparseable `ts` no cap slot, and never archives a parent
  with a live child. Live design doc §9.14; walkthrough §2.23.
- **The wiki ledger is an event log** (`bin/published.py`, v0.24.10, #392).
  `.work/published.json` became `.work/published.jsonl`: append-only,
  union-merged, folded last-writer-wins per key, one writer. `worklog wiki-add`,
  `wiki-record`, `wiki-get` are its only readers and writers; `worklog wiki-plan`
  is the publish dispatcher with the frozen guard and the render-hash skip. Live
  design doc §8.10; walkthrough §2.26.
- **Event routing is configuration** (`bin/triggers.py`, v0.24.10). `worklog
  triggers <event>` reads the `triggers:` block of `.work/config.yml`; skills and
  the post-merge workflow run what comes back. Walkthrough §2.27.
- **The merge pipeline** (v0.24.10, ADR-0010, ADR-0011). A ruleset on `main`
  requires the `invariants` and `coverage` checks and merge commits only. The
  nightly compaction and the new `post-merge.yml` open PRs and arm auto-merge
  instead of pushing. Bot PRs turn green through an interim status bridge,
  `plugin/scripts/associate-pr-checks.sh`, which ADR-0011 marks for deletion
  once a maintainer PAT exists. After the tag, `worklog-invariants` became
  read-only and the dead bypass actor left the ruleset. Live design doc §8.9
  and §9.16; walkthrough §2.25.
- **Three sources for the remote key** (`bin/sync_dispatch.py`, v0.24.8 to
  #412). `remembered_key()` consults the folded `external.key`, then the
  per-clone `last_pushed_key`, then the remote marker map that
  `observe_remote()` builds from the listing it already makes. A closed remote
  closes the item locally. New commands: `worklog adopt`, `worklog dedupe`,
  `sync --explain`, `sync --report`. Live design doc §9.15; walkthrough §2.24.
- **The write envelope** (v0.24.10). `append()` caps the whole encoded event at
  `PIPE_BUF`, checks the write count, and holds `.work/.lock` against
  compaction; `ulid.new()` is monotonic within a millisecond; compaction
  re-emits open conflicts above each snapshot instead of dropping them.
- **Generated files stop conflicting** (v0.24.8, #381). `docs/roadmap.md` and
  `docs/.index/**` carry `merge=ours`; `hooks/pre-merge-commit` regenerates
  them from the union-merged log before the freshness gate.
- **Three hosts** (v0.24.4). `plugin/hooks/cursor-hooks.json` joins the Claude
  Code and Codex manifests over one shared script tree.
- **Install and wiring repairs** (v0.24.7). `init.sh` installs `doc_verify.py`,
  `provenance.py` and `hooks/session-end.sh`; the SessionStart doctor writes
  `merge.ours.driver` and `core.hooksPath`; `docs/design/` (singular) is
  classified as a design document.
- **The freeze cap** (v0.24.10). This note is the shape a release freeze now
  takes.

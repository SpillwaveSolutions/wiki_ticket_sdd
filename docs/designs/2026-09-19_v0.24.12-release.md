# Design freeze: v0.24.12

not a copy of the live pair. v0.24.12 shipped the same day as v0.24.11 and
closes the plan `docs/plans/2026-09-19-review-v0-24-10-and-open-tickets.md`

## What the cut-over proved

ADR-0011 was accepted before the secret existed, so its central claim was
untested: that a real identity makes the gate's answer come from GitHub rather
than from a script. Two `worklog-compact` dispatches settled it. Both reached
`commit via PR`. The resulting bot PR carried native `worklog-invariants` runs
for both `pull_request` and `push`, merged itself through auto-merge, and
deleted its branch. The nightly run that followed landed with nobody watching.

Two findings worth carrying forward:

1. A fine-grained PAT whose resource owner defaults to the maintainer's
   personal account authenticates but cannot push to an organization
   repository. The push fails with `403 ... denied to <user>` even when that
   user is an org admin. The token's resource owner must be the organization,
   or the token must be a classic one with the `repo` scope.
2. Supersede-not-rebase resolves the sequential case, which is the nightly
   one. Two jobs dispatched seconds apart can each open a PR before either can
   close the other, and the loser needs a manual close.
